Performance Analysis of a Basic Organic Rankine Cycle (ORC) Using Nano-Organic Fluid
Project Overview:

Bachelor's thesis focused on the thermodynamic performance analysis of a basic Organic Rankine Cycle (ORC) using nano-organic fluids.

Research Objectives

1.Analyse the performance of a basic ORC system.

2.Investigate the use of R123 as a working fluid.

3.Study Al₂O₃–R123 nanofluid for improving thermal performance.

C.ompare the thermodynamic performance of different working fluids.

Software Used

Engineering Equation Solver (EES)

Academic Background

Degree: Bachelor of Engineering in Mechanical Engineering

University: Mehran University of Engineering & Technology, Pakistan
